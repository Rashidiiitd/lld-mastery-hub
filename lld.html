How to use this plan

  1. Read the concept from first principles.

MEDIUMUML + OOP

Design a Parking Lot

Model parking spots, vehicles, tickets, entry/exit gates, and fee calculation.

  • Identify core entities and responsibilities
  • Draw associations and multiplicities
  • Discuss concurrency at entry/exit
MEDIUMDESIGN PATTERNS

Payment Processing

Support multiple payment providers without putting provider-specific logic in checkout.

  • Compare Strategy and Factory Method
  • Define a stable payment interface
  • Consider failure and retries
HARDCONCURRENCY

Thread-safe Logger

Design a logger that can be called from multiple threads without corrupting output.

  • Discuss shared state and data races
  • Compare mutex and queue-based designs
  • Define shutdown behavior
